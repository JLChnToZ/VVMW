# Contributing

Thanks for considering a contribution!

## AI-Assisted Contributions

AI tools are allowed. However, **you** (the human contributor) must personally audit every change and take full responsibility for what you commit.

### Requirements

- Review and understand all code you submit (whether written by you, an AI, or both).
- Check for correctness, security issues, and compliance with the project’s style (enforced via EditorConfig).
- By opening a pull request you confirm that you have audited the changes and accept responsibility for them.

When using an agent-generated pull request description, review the entire
description and changes, complete the AI Audit Confirmation, and personally
remove the `AI-AUDIT-REVIEW-REQUIRED` marker. The PR audit check fails while
the marker remains; it cannot verify that a human performed the audit.

## Style

Code style is enforced with [EditorConfig](https://editorconfig.org/). Please make sure your editor respects the `.editorconfig` file.

## How to Contribute

1. Fork the repository and create a branch.
2. Make your changes.
3. Open a pull request with a clear description and the AI Audit Confirmation (if AI was used).

That’s it. Keep changes focused and easy to review.
